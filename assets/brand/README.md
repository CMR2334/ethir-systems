# Ethir Systems selected mark

Selected direction: **Classic E**.

## Color system

- Forest: `#29352e`
- Bright gold on forest: `#e3b737`
- Antique gold on white: `#835700`
- White: `#ffffff`

## Files

- `ethir-mark-forest.svg` — primary square mark for profiles, cards, and dark-brand applications.
- `ethir-mark-white.svg` — square companion mark for white applications.
- `ethir-mark-transparent-forest.svg` — forest letterform and antique-gold dot with no background.
- `ethir-mark-transparent-light.svg` — white letterform and bright-gold dot with no background.
- `ethir-mark-forest-512.png` — standard profile/avatar export.
- `ethir-mark-forest-1024.png` — high-resolution social/profile export.
- `ethir-mark-white-512.png` — light companion raster export.

The letterform is stored as an SVG path rather than live font text, so it renders consistently across browsers and devices.
